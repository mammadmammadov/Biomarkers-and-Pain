# Biomarkers-and-Pain 🧬

## Running the Code

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/mammadmammadov/Biomarkers-and-Pain.git
    cd Biomarkers-and-Pain
    code .
    ```

2.  **(Recommended, but you can do it differently based on your preference) Create a virtual environment, you can also do it with conda:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```

3.  **Install dependencies:**
    All required libraries are listed in `requirements.txt`. Install them using the following command:
    ```bash
    pip install -r requirements.txt
    ```
